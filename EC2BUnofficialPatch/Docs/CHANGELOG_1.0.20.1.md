# EC2BUnofficialPatch 1.0.20.1

## 修复

- 修复社交阶段中由 Option 打开的原版小游戏可能无法推进阶段的问题。
- Option 打开的小游戏现在会在具体 View 关闭时优先读取胜负并回写阶段，原版后续回调只负责继续对话流程，不再造成第二次结算。
- 回调型小游戏也会安装 CloseView 观察补丁，但只在 Option 内嵌启动时接管；Talk 结束后自动打开的小游戏仍保持原有回调结算流程。
- 失败分支没有独立 fail 回调时，Option 与 Talk 均会继续使用原版放在 success 槽中的阶段流程回调。

## 兼容性

- 保留 1.0.20 的单次结算保护和小游戏参数适配逻辑。
- 程序集版本继续保持 `1.0.9.0`，避免破坏按稳定程序集版本引用补丁的插件。
