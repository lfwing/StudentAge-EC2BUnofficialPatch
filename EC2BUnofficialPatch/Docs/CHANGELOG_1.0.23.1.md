# UP 1.0.23.1

面向游戏1.94，继续使用已内置BetterAudio的单个EC2BUnofficialPatch.dll。本文描述当前源码和本地发布候选；Git提交、Release附件和工坊发布分别进行。

## 玩家可见的变化

- 特质说明代入实际属性名、数值和百分比；已解锁候选达到四项时可显示前四张，保留原有关系门槛。过长正文可展开原版风格的滚动说明窗口。
- 新效果支持连续行动双/三倍属性、无损追加行动、属性获取率、增减消耗、减耗奖励、社交回合奖励、心情系数和挚友备选借用；20/5418可解除特质卡片切换冷却。
- 角色社交与空间可见性分开控制。空间动态、日志、评论、留言、回复和署名点赞可正常发布后隐藏，揭示时保持原发布时间和相对时间顺序，图片跟随所属内容。
- 控制台输入框获得焦点后，上/下方向键可调取本次运行已提交的命令，向下越过最新项恢复草稿。该开关默认开启，自动打开控制台仍单独配置且默认关闭。
- F9的羽毛球、地图登记和场景对象提供者各自比较输入；未修改对应资源时跳过，避免只改特质仍重复报告其他功能全量更新。
- 保留既有地图制作台、场景对象、跨Mod羽毛球球服、CG图鉴、Live2D、音频/视频及小游戏扩展。

属性获取率只接受带子类型1的八项格式，旧1/102、999/50不作为新入口；消耗固定增减/节点减免必须五项，不支持错误的四项简写。可消耗属性由PersonAttrCfg.consume=1/2决定，不能把消耗模式1/2当作属性ID。

同一属性的增耗和减耗先加法相消，最终系数最低0；不会反向恢复。减耗奖励只按自身实际贡献计算，随机属性范围0/1/2/3/4/7/11/30，保留原版获取率和变化提示。行动扩展纳入打工、吃饭，排除事件和小游戏；不重复事件窗口或小游戏阶段。洞察仅展开目标已解锁的挚友备选，保留门槛并阻止递归，不包含至交。

## 角色可见性与存档

RoleAvailabilityCfg.roles增加可选hiddenkzone，默认false。cond只控制默认社交并参与原有考试检查；takeExam仍必填。显示/隐藏指令的决定高于默认配置，保存在当前存档，F9不清除。

批量空间指令只处理执行时已发布且需要改变状态的作者内容，不预约未来内容、不补发缺失内容、不重复发布奖励。父项隐藏时，子项暂时不可见，自己的显示决定保留。留言板、留言回复及在别人空间留下的署名互动均按作者处理。

完整JSON、全部效果及组合示例见[RoleAvailability说明](../ModAuthorTemplate/RoleAvailability说明.txt)。

## 配置与迁移

cfg按优化、机制、效果、前提、指令、替换规则、Debug、更新分组，优先保留当前项，缺项继承旧分类/旧名称。新效果和新前提开关描述保持简短，具体语法查数据格式。完整默认配置见[使用说明](../../README.md#43-功能开关)。

F9修改已选特质effect后，需切到其他特质再切回，以重建UID；卡片文案更新本身不等于旧节点已经更换。四候选显示不自动解锁，通常仅所选卡片生效；洞察按其独立机制额外展开备选。

插件、产品和文件版本为1.0.23.1，程序集绑定版本保持1.0.9.0。旧Mod资源目录和音频协议继续兼容。曾安装1.0.24/1.0.25接手测试版者需手动替换一次；自动更新不执行降级。

## 构建与验证

两种net472构建通过，438项实际效果/条件/模块挂钩/序列化及布局契约检查通过。CLR隔离夹具不执行真实Unity画面、实际方向键输入或完整磁盘存读档；这些仍应实机复测，不能将构建成功当作全部视觉验收。详见[验证记录](../../Docs/VALIDATION.md)。

dist/release中的DLL与三处update.json按实际大小和SHA-256同步。维护者随后手动上传同次构建的DLL及update.json，详见[发布步骤](../../Docs/AUTO_UPDATE.md)。
