# EC2BUnofficialPatch 1.0.21

## 新增与修复

- 新增默认开启的 `[机制] 地图社交界面外置Live2D`：为地图角色交互界面中的静态 Mod 角色按“角色 + 当前服装”直接加载外置 `model3.json` / `moc3`。
- 外置 Live2D 的 PNG 改由 Unity 异步纹理通道读取和解码；遮罩接入游戏原有 Cubism 绘制链。相同模型重复打开时复用实例，并消除同一次加载中的重复文件读取。
- 外置 Live2D 成功日志按模型在单次游戏进程内只输出一次；失败日志继续保留。
- 新增 `[优化] 静态立绘优化输出日志 = false`，可在不关闭静态立绘优化的情况下单独启用诊断输出。
- 外置模型使用游戏自带 Cubism SDK/Core，支持 `model3.json` 引用的 PNG 纹理与可选 `physics3.json`；不随 Mod 分发另一套 Cubism DLL。
- 外置模型默认按静态立绘已应用的 Person 位置/缩放及非透明像素范围，与可见 Drawable 自动等高；新增两组归一化锚点和 `fitScale/xOffset/yOffset` 微调，并兼容旧绝对 `scale/x/y`。
- 外置模型登记新增 `schoolStage=primary/middle/all`，同一角色与服装可以分别配置小学和中学模型，旧配置省略该字段时继续作为跨学段共用项。
- 修复外置模型瞳孔等剪贴 Drawable 无法正确显示的问题。
- 无需 `motion3.json` 即可按模型实际存在的标准参数提供轻微待机、呼吸、眨眼、鼠标头部/眼球跟随，并将输入传给可用物理。
- 模型文件缺失、路径越界、PNG 损坏、moc 校验/版本不兼容或实例化失败时，自动恢复现有静态立绘。
- 补齐地图角色交互界面的静态 Mod 角色随机服装显示：普通地图使用角色本回合 `ClothId`，学校地图保持 1 号校服；静态差分缺失时回退 0 号常服。
- 新增 `[Debug] AutoOpenGameConsole` 配置；开启后在游戏启动时自动显示游戏内 `DebugView` 控制台，默认关闭。

## 兼容性

- 外置 L2D 与地图静态服装模块共用当前服装判定，但不修改服装解锁状态、`Role.ClothId` 或静态服装回退规则。
- 两个地图模块都只作用于 `MapRoleView`；原版角色、原版 Live2D、`DetailSocialView`、Talk 表情、剧情 3006 与原版 Addressables 路径保持不变。
- 控制台继续使用原版输入框聚焦、反引号切换、Esc 关闭与 ActionMap 切换逻辑。
- 保留 1.0.20.1 的社交小游戏结算修复；程序集版本继续保持 `1.0.9.0`。
