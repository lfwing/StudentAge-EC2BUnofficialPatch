MapExtend 地图与场景制作台（UP 1.0.23.1 / 兼容的独立MapExtend通用）
打开 map-extend.html，统一制作大地图、父/子地点、标点与场景点击对象。
流程：01项目与资料 → 02大地图 → 03地点与标点 → 04场景对象 → 05检查与导出。
场景对象的小流程：场景 / 对象 / 点击行为 / 图片与区域，资料默认展开。只做对象无需新增大地图。
手动填写场景 MapId / BgId 和坐标宽高，导入对应场景参考图；建议用解包背景原图。无需先在游戏里建成地点，也无需导入游戏坐标文件或原版人物表。坐标宽高默认2560×1440，按实际背景局部坐标尺寸调整，不一定等于图片像素尺寸。
原版使用 PersonCfg 承担场景物件。对象名字自行填写，默认 MapId-BgId-xx；人物编号、介绍和音效由“生成 / 更新原版 PersonCfg 行”按钮单独生成，保存对象不改人物表。PersonCfg 只输出对象的纯净原版行：id、name、init=[-1]、introduction、clickAudio，不夹带整份原版人物表或其他字段，供作者自行注册。
普通图显示条件和可点击条件独立；前者留空始终显示普通图，后者留空默认可点击并显示悬停图。没有普通图也可点击背景中已画好的物件。两者都以所属地点及实际背景为范围。
条件/效果按原版填写：1,1,1,10;100,10,100001，英文逗号分参数、英文分号分组。不要手写 []，工具导出时自动转换为二维数组。普通条件组按原版同时满足。
四种行为任选一：仅介绍、介绍同时执行效果、切指定 BgId 背景、切指定 MapId 场景。只有当前行为的专用内容显示。背景与场景 ID 均须已注册。
切场景复用 UP 的 100,1,MapId，支持父/子地点和家1；此移动会解锁目标地点，可点击条件用于控制入口。回家指令与对象点击共用原版圆形遮罩过渡。
普通图平时显示，命中且可点击时悬停图替换普通图；移出恢复。图片位置/尺寸独立，命中区独立，可不用普通图。场景画布支持 Ctrl+滚轮、空格/中键平移、拖动图片及尺寸手柄、锁比例、圈选/移点/删点。预览不判断游戏剧情条件。
UP新增物件介绍保留当前背景与本场景应显示的普通图，介绍时收起悬停图；在家沿用原版模糊遮罩，地图场景复用当前已显示的背景精灵，不重新读取BgCfg原图。普通图仍受各自条件和100,11显示/隐藏效果控制，介绍结束后恢复场景交互。原版物件的介绍流程不改动。
大地图用 MapLayout.json 校准标签与坐标；场景采用中心原点、Y向上坐标。场景坐标宽高与地点/背景绑定写入 SceneObjectscfg.json 的 scenes 设置，重开模组内容时直接读取。场景参考图只用于本次编辑，不导出；玩家需自行额外导入参考图。
场景按 MapId + BgId 分开保存和显示；当前场景的所有对象选区与图片同时保留，切换场景不会迁移对象。已保存场景可来回切换，导出后重开仍按同一归属恢复。填写或修改 MapId/BgId 后必须点击“确认场景（创建 / 切换）”，输入过程不创建场景、不切换当前编辑范围；确认的空场景也随模组保存。可在已保存场景选框下删除当前场景，含对象、参考图或自定义尺寸时再次确认；删除对象、选区、参考图及独占图片/人物行，共享内容保留；需要主动迁移对象或校正旧版误存的归属时，在“对象”页使用“调整此对象的所属场景”，图片位置、尺寸和选区保持不变。
一个项目共享 PNG、MapCfg/BgCfg/PersonCfg/EvtCfg/TalkCfg 材料，统一导出 MapExtend.zip。解压后的模组内容可通过“打开已有项目”直接读取并继续编辑，不生成 Editor 文件夹或额外项目资料。保存当前编辑保留网页内数据；导出ZIP才保存到磁盘。Ctrl+S 保存当前编辑。
请按原版 Mod 流程注册 Cfg/*.json。UP和独立MapExtend均不会自动读取 MapExtend/Cfg。原版 type=30 物件事件另配 EvtCfg/TalkCfg；新四种点击行为不会自动消费该事件队列。
安装推荐 Mod/EC2BUnofficialPatch/MapExtend，其次 Mod/MapExtend，也支持其他容器中的 MapExtend。PNG 路径相对扩展JSON目录。模板生成位置与流程不变。
Worldmapscfg schema=1、MapLocationscfg schema=2；新 SceneObjectscfg schema=2。DLL 保留旧 schema=1 读取；旧非空对象配置需按新流程重新登记，工具不会擅自改其行为。
F9可刷新扩展JSON/图片；地图登记与场景对象分别比较自己的输入，无变化跳过，不会因为只修改TraitsCfg而重复刷新。地图登记需关闭重开地图查看，当前场景对象可刷新；原版CFG及资源新增仍按原版规则重启游戏。
大地图和父地点 ID 自行填写；大地图名称留空默认“新区域<ID>”。
勾选交通入口后，父地点自动开放强制勾选且不可取消，第二步清单也不能去掉其 ID；取消交通入口后恢复可调整，但不自动取消勾选。自动开放不会反向设置交通入口。
交通父地点在大地图解锁时自动开放，子地点仍独立选择，不随入口全部开放；鹅城12保留原版剧情解锁，只初始化一次，不覆盖既有剧情锁定。
子地点固定生成 type=2；ID 整除1000必须等于父ID（父ID×1000+0～999），不可重复、不可超过2147483647。建议尾号从001开始，不建议直接使用000。非法输入不会改动原版表。

文件读取报错时：不要刷新或关闭工具，也不要重新导入替换编辑。点击“抢救当前编辑”，下载并检查抢救备份和说明。导入的内容与PNG在读取成功时复制为内存Blob，导出不再依赖本地文件引用；原文件之后被移动、替换或权限变化不会影响已缓存内容。导出读取失败会显示具体相对路径，并提示保留页面及使用“抢救当前编辑”。抢救包保留当前配置/选区、未保存表单和可读取图片；不可读取PNG尽量从已解码图片重建，说明中列出重建及仍需补入的文件，不将不完整抢救包宣称为完整模组包。

场景物件效果：100,11,1,PersonId 显示普通图；100,11,-1,PersonId 隐藏普通图；100,11,2,PersonId 允许点击及悬停；100,11,-2,PersonId 禁止点击及悬停。
这些指令独立于普通图显示条件/可点击条件，不改写条件。未执行指令时遵循条件；执行后相应方面以最后一次明确指令为准，显示和点击状态互不影响，并随存档保存。仍限于对象所属地点及背景。旧存档没有指令记录时继续按条件判断。
PersonId 必须已按原版注册，且在启用内容的 SceneObjectscfg.json 中能找到对象。显示/隐藏要求普通图；可点击/不可点击要求普通图或悬停图至少一张；没有所需图时不记入状态并提示日志。相同 PersonId 绑定的多个对象共享这一状态，需独立控制时使用不同人物编号。兼容运行时旧 schema=1 对象。
移动指令 100,1,MapId 已归入 MapExtendEffects/MapMoveService，复用原有父/子地点与回家过渡；同时启用移动修复和地图扩展只注册一次。

独立MapExtend插件与完整版UP使用同一模组格式、作者工具、生成目录和WorldMaps.v2存档键，制作内容可互通，无需转换。工具生成位置仍是BepInEx/plugins/EC2BUnofficialPatch/MapExtend，不因DLL放在MapExtend目录而改变。两版共存时优先使用已启用的UP地图模块，独立版不重复读取和注册；UP地图模块关闭时由独立版补齐，移动效果和子地点提供者仍各保留一份。不要复制两套相同的模组内容或安装多份同名DLL。
