04 / SCENE OBJECTS

场景与制作资料

原版用 PersonCfg 表示场景里的可点击物件：它在配置上是一个“角色”，不必是真正的人物。手动填写所属地点与背景 ID，再导入参考图定位对象；无需先进入游戏生成坐标文件，也无需导入人物表。

制作另一个场景时选择“新建场景”，再填写它的地点与背景 ID，并点击“确认场景”；已有场景及对象会保留。
场景设置与参考图

填写这两个 ID 后，点击“确认场景”才创建或切换；未确认输入不会影响当前场景，也不会迁移已有对象。只显示该地点和背景中的对象；不要求地点已经在游戏里建成。地点与背景在安装内容时须按原版 Mod 流程注册。 参考图不随模组导出；重新打开 MapExtend 内容后，请自行额外导入。建议使用对应的解包背景原图；坐标以背景中心为原点，Y 向上。宽高表示游戏背景的局部坐标尺寸，默认 2560 × 1440，可手动调整；图片像素尺寸与坐标尺寸可以不同。
人物行与事件注册说明 在“对象”页填写人物 ID、介绍与点击音效，点击生成原版 PersonCfg 行。导出 Cfg/PersonCfg.json 只含对象的纯净原版行，不包含整份原版人物表，也不生成 kzoneHeadId；请自行注册到 Mod。 原版物件事件另用 EvtCfg.type=30、npc=PersonCfg ID 并配套 TalkCfg。本工具的四种点击行为按右侧选择执行，不自动消费原版物件事件队列；需要剧情效果时选择“触发介绍的同时执行效果”。

02 / WORLD MAP
选择或新增大地图
只在鹅城新增父地点：保留大地图 0。新增另一张大地图：点下方“新建大地图”，选择底图，再添加车站和其他父地点。
新区域必须有车站。到“父地点”页创建车站并勾选“交通入口”，工具会维护 mapIds / travelMaps；右键默认进入第一座车站。
解锁大地图时自动开放的父地点大地图必须要有至少一个交通入口。这里与父地点页的自动开放选项实时同步；子地点的自动开放请在子地点页设置。
功能固定为 160，由 DLL 内置。剧情用 [101,1,160] 开启功能；[101,5,地图ID] 开放地图，[101,-5,地图ID] 移除地图。提前开放地图会被记住，但不会提前开启功能或特殊行动。
鹅城固定为 0、客运站 12 固定登记且不默认解锁。地图 ID 与原版地点 ID 分开，地图 ID 最大 16777215。坐标宽高是游戏内显示尺寸，与 PNG 像素可不同。“扩展已有地图”只贡献地点，底图和默认开放状态由原地图作者定义；可导入其 PNG 用于对齐，参考底图不打包。



原版子地点与背景
此处只生成原版注册材料。MapExtend/Cfg 不会被插件读取，导出后必须按原版 Mod 流程注册。
为当前父地点新增子地点
先生成父地点原版行（无需先圈选）。原版规则：子地点 ID 整除 1000 必须等于父地点 ID，即父地点 ID × 1000 + 0～999（例如父地点 31 对应 31000～31999）。建议子地点尾号从 001 开始，不建议直接使用 000 尾号。ID 不能重复，最大 2147483647；超出范围会拒绝生成。子地点固定生成 type=2，不用圈选或放标签；floors 会包含父地点本身与子地点 ID。复杂配置可在下方编辑原版 JSON。
生成子地点场景背景行
这里是进入地点后的场景背景；大地图底图在①中设置。资源 URL 遵循原版资源注册，不能直接使用 MapExtend/Images 的 PNG 磁盘路径。
原版 MapCfg / BgCfg 导入与编辑保持原版“ID → 对象”的 JSON 结构。未知字段保留。先导入原有表再修改，可避免丢失已有行。

地点数据与解锁说明这里制作父地点的大地图入口。下方可生成原版 MapCfg 行；子地点去“子地点 / CFG”页添加。原版条件、楼层等高级字段可直接编辑原版表。同值时新增入口在原版之后，新增之间较大 ID 响应；设为 1 可位于原版之下。所有标点遵循原版地点解锁、条件和 NPC 显示规则。
