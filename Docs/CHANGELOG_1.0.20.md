# EC2BUnofficialPatch 1.0.20

## 机制：社交小游戏大修

- 不再用一个统一空参数入口强制启动全部原版小游戏，改为逐项建立 Level 启动契约。
- 钢琴、戳指缝、数独、拼图等可独立运行的玩法使用专门启动适配器，并校验对应 mode、parms 与依赖 CFG。
- 依赖 Talk、Option、Evt 或特殊回调上下文的玩法只允许从原版上下文内嵌启动。
- 区分原版 EndGame、回调和关闭观察三类结算所有权，阻止重复属性与奖励结算。

## 优化：地图子地点兼容与扩展

- 新增配置项 `[优化] 多mod地图子地点兼容 = true`：将多个mod中声明的父地图地点合并，未声明的子地图按照官方规则注册。
- 新增配置项 `[优化] 地图子地点扩展 = false`：允许子地点继续包含下一层；必须由Mod作者和玩家同时启用，因此默认关闭。
- 父地图普通字段继续按原版 Mod 优先级覆盖，`floors` 改为汇总所有 Mod 的有效声明并去重。
- 显式 `floors` 可登记任意已存在地图ID，并据此建立子地图到父地图的反向索引；不再强制要求ID/1000匹配。
- `type == 2` 地图可继续声明下一层：自身与祖先ID作为导航项，其余有效ID建立为直接子地图；叶子地图显示直接父层，容器地图显示自己的下一层。
- 循环关系会被忽略；多父冲突保留先建立的父关系，避免错误列表反向污染已经确定的层级。
- 只有未被任何父地图声明的 `type == 2` 地图才按 `子地图ID / 1000` 兜底自动注册；F9热重载后重新构建关系。
- 无效归属或父地图不存在时跳过注册并记录警告，不修改 Workshop 原文件。

## 优化：Steam 昵称对话替换

- 新增配置项 `[优化] Steam昵称对话替换 = true`。
- 仅将严格连续、顺序完全一致的 `{1}{2}{3}` 整体替换为当前 Steam 昵称。
- `{3}{2}{1}`、`{1}{2}`、`{1} {2}{3}` 和全角括号写法均保持原版替换规则。
- Steam 平台或昵称不可用时安全回退到原版姓名替换。

## 优化：.json 文件热重载

- 新增配置项 `[优化] .json文件热重载 = true`，游戏内按 `F9` 执行，避开原版 F8 快速读档。
- 普通 Mod `*Cfg.json` 使用事务式重载：完整解析成功后才替换原运行时 `CfgMap`；支持修改、增加和删除条目，并保持启动时的 Mod 顺序与重复 ID 优先级。
- UP 当前的 `Custompaper.json`、歌词 JSON、`RoleAvailabilityCfg.json`、`CustomMinigamecfg.json` 以及漫画、情侣画等外置资源索引会整体重建。
- 内置兼容当前 BetterAudio：重新发现、预检并注册 `BetterAudio.json`，不需要修改 BA。
- 新增公开 `JsonHotReloadApi`。其他 DLL 插件按规则注册自己的原子重载回调后，其新增 JSON 无需 UP 特判。
- 热重载仅作用于 JSON 配置和由其生成的运行时注册表，不替换 DLL，不重新安装 Harmony 补丁，也不重建游戏存档或已经打开的玩法流程。
- F9 使用游戏当前启用的 Unity Input System，避免旧 `UnityEngine.Input` 在每帧轮询时抛出异常并刷满日志。
- 普通 Mod CFG 按文件隔离错误：损坏文件保留上一次有效注册，其他 Mod 的有效变更继续应用；日志只列出发生新增、修改或删除的文件与条目 ID。
- BetterAudio热重载不再依赖可能已被Unity销毁的插件组件实例，改为调用其静态发现器与ConfigStore注册入口。

配置说明：

```ini
## 游戏内按F9可实现.json文件热重载，其余插件新增.json可按规则兼容。 默认：True。
# Setting type: Boolean
# Default value: true
.json文件热重载 = true
```

其余新增配置：

```ini
多mod地图子地点兼容 = true
地图子地点扩展 = false
Steam昵称对话替换 = true
```
